실험 목록

새 실험 준비

정책안 숫자·산식은 자동으로 만들지 않습니다. 연구책임자가 승인한 값만 입력하고, 동결표 승인 전에는 수집이 열리지 않습니다.

출처 등록

공개 HTTPS 원문과 허용 호스트만 등록합니다. 비공개 원문은 챗봇 지식으로 가져오지 않습니다.

지식 작성·승인

작성자·검토 요청자와 승인자는 달라야 합니다. 승인 취소 즉시 공개 검색에서 제외됩니다.

정책동향 배치

설정과 수동 요청만 기록합니다. 자동 발행은 없으며 기본 OFF입니다.

근거형 챗봇

# 연구 데이터 공개 경계

> 기계가 읽는 정본은 `.agents/context/research-data.yaml`이다. 기준일은 2026년 7월 31일이다.

과거 합성 실행 자료는 미공개 전문가안과 내부 운영 자료에서 파생된 입력을 포함해 공개 저장소와
사이트에서 철회했다. `instances/`, 정적 결과 페이지, 원문·집계 다운로드를 공개 배포에 포함하지
않는다.

공개할 수 있는 것은 공개 라이선스와 출처가 확인된 합성 데이터 생성 코드, 데이터 계약, 방어장치,
그리고 공개가 확인된 정책 입력으로 새로 재현한 결과뿐이다. 수신 문서, 미공개 정책안, 회의·진행안,
리허설 프롬프트, AI 검토 원문, 운영자 계정, 실제 참여자 원시 응답은 비공개 저장소에서 관리한다.

다시 공개하려면 입력의 공개 상태·저작권·개인정보를 확인하고, 공개 입력만으로 새 실행을 만든 뒤
비공개 정보 검사와 사람의 Pull Request 승인을 거친다.

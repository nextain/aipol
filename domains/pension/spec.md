# 연금 도메인 명세

- 상태: 공개 레퍼런스 명세
- 실행 계약: `../../docs/aipol-execution-contract.md`
- 상위 문서: `../../RFC-0001-framework.md`

이 문서는 연금개혁을 AIPOL의 도메인 플러그인으로 구현할 때 필요한 공개 계약만 기록한다. 행사
진행안, 회의에서 정한 운영 순서, 참여자 구성, 미공개 자료와 담당자 정보는 비공개 저장소에서
관리한다.

## 1. 정책 변수

연금 플러그인은 수급 시점, 재정 투입 방식, 기초연금 설계처럼 공개 검토가 가능한 정책 변수를
도메인 레버로 표현한다. 실제 실험에서 사용할 값과 선택지는 승인된 정책 정본에서 별도로 동결한다.
공개 코드의 예시값을 현재 정부안이나 행사 확정안으로 간주하지 않는다.

## 2. 근거 계약

- 법령, 정부 발표, 공식 재정계산 등 출처가 확인되는 자료만 근거 앵커로 등록한다.
- 숫자에는 기준연도, 가정, 출처 버전을 함께 기록한다.
- 서로 다른 기준선의 수치를 합치지 않는다.
- 라이브 생성물이 승인된 앵커와 어긋나면 차단한다.
- 공개되지 않은 수신 문서와 회의 자료는 이 저장소에 복사하거나 요약해 넣지 않는다.

구체적인 공개 근거는 공개 출처 URL과 버전을 함께 기록하며, 운영 검증 기록은 비공개 운영 저장소에서 관리한다.

## 3. 영향 모델

- 입력: 승인된 정책 변수 조합과 기준선
- 출력: 재정 지속가능성, 세대별 부담, 보장성에 관한 방향성과 범위
- 정밀한 단일 예측값은 공인 추계모형과 검증 계약이 없으면 제시하지 않는다.
- 언어모델은 계산 결과를 설명할 수 있지만 계산 자체를 대신하지 않는다.

## 4. 측정과 세그먼트

측정 문항과 척도는 비교 시점 사이에 유지한다. 세그먼트는 연구 목적과 최소수집 원칙에 따라 사전
승인하며, 작은 집단의 재식별 위험이 있는 분포나 원시 응답은 공개하지 않는다. 합성 참여자와 실제
참여자 데이터는 저장·분석·표시 단계에서 분리한다.

## 5. AI 산출물 계약

AI 산출물은 다음 항목을 포함한다.

- 사용한 공개 근거와 버전
- 전문가안과 달라진 부분
- 예상 수혜·부담과 상충관계
- 반영하지 않은 의견과 이유
- 검토자와 승인 상태
- 남은 불확실성과 한계

입력값은 허용된 정책 변수와 범위로 제한한다. 자유서술은 명령으로 실행하지 않고 분석 대상 데이터로
취급한다. 사람 승인 전 AI 산출물을 확정 정책안이나 행사 노출물로 표시하지 않는다.

## 6. 공개 실행 경계

공개 저장소는 상태 전이, 동일 문항 비교, 변경 불가 기록, 출처 계보, 사람 승인 같은 재사용 가능한
계약을 제공한다. 실제 행사의 순서·시간표·참여자 배분·발언 구성·운영 메모는 공개 코드 계약이
아니며 비공개 운영 자료로 관리한다.

결과 보고 시에는 관찰된 선택 변화만 기술하고 특정 노출이 변화를 일으켰다는 인과 주장을 자동으로
만들지 않는다. 실제 여론, 대표 표본, 미래 정책 효과로 일반화하지 않는다.

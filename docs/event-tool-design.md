# 행사 도구 공개 설계

이 문서는 공개 가능한 소프트웨어 계약만 설명한다. 특정 행사의 진행 순서와 내부 결정은 포함하지 않는다.

## 역할

- 참가자: 익명 세션으로 의견을 제출하고 자신의 제출 상태를 확인한다.
- 검토자: 생성된 대안과 근거를 검토한다.
- 운영자: 수집 상태를 열고 닫으며 감사 기록을 확인한다.

## 불변식

- 승인되지 않은 AI 산출물은 참가자 화면에 노출하지 않는다.
- 실제 참가자와 합성 참여자를 분리한다.
- 중복 제출과 세션 탈취를 방지한다.
- 수집 종료 뒤 원시 응답을 정적 공개물에 포함하지 않는다.
- 보고에는 표본과 대표성의 한계를 함께 표시한다.

행사별 운영 절차, 계정 배정, 연락처, 수신 문서와 정책 입력값은 비공개 운영 저장소에서 관리한다.

# 250명 동시 참여 경로 JMeter 성능시험

2026년 8월 14일, AIPOL 연금정책실험의 공개 참가 경로를 대상으로 250개의 서로 다른 참여자 세션을 사용한 외부 부하시험을 수행했다.

## 한눈에 보는 결과

| 항목 | 결과 |
|---|---:|
| 참여자 프로파일 | 250개, 토큰 중복 0 |
| 전체 요청 | 8,000건 |
| 성공 | 8,000건(100%) |
| 전체 응답시간 | p50 10ms · p95 20ms · p99 46ms · 최대 241ms |
| 페이지 진입 | 250/250, p95 20ms |
| 상태 폴링 | 7,500/7,500, p95 15ms |
| 1차 투표 저장 | 250/250, p95 56ms |
| DB 확인 | 고유 참여자 250명 · M1 응답자 250명 |
| 서비스 안정성 | 앱 재시작 0회 · 시험 시간대 오류 로그 0건 |

사전 기준인 성공률 99.5% 이상, p95 2초 미만, 투표 250/250을 모두 충족했다.

## 무엇을 측정했나

두 개의 별도 Azure VM에서 Apache JMeter 5.6.3을 실행했다. 실행기마다 125명의 고유 프로파일을 배정하고 실제 공개 도메인을 통해 다음 경로를 측정했다.

```text
JMeter A 125명 ─┐
                 ├─ 공개 인터넷/DNS/TLS ─ nginx ─ Node(vinext) ─ PostgreSQL
JMeter B 125명 ─┘
```

각 참여자는 참가자 페이지를 한 번 열고, 이벤트 상태를 10초 간격으로 30회 조회하며, 1차 투표를 한 번 저장했다. 투표는 60초 범위에 분산했다. 전체 유효 실행은 약 7분이었다.

부하발생기 평균 CPU 사용률은 약 0.5%여서 실행기 자체 병목 징후는 없었다. 서버 측에서는 앱 VM CPU가 평균 1.96%, 최대 3.72%였고, PostgreSQL CPU는 평균 20.76%, 1분 최대 84.61%였다. 이번 250명 시나리오는 안정적으로 처리했지만 더 큰 규모에서는 DB를 우선 관찰해야 한다.

## “250명”의 의미

이 시험의 250명은 실제 사람을 모집한 조사가 아니다. 서로 다른 참여자 토큰과 비식별 합성 프로파일을 가진 250개의 가상사용자 세션이다. 따라서 다음과 같이 해석해야 한다.

- 말할 수 있는 것: 정의한 250명 접속·폴링·투표 부하에서 웹서비스가 정상 작동했다.
- 말할 수 없는 것: 250명의 정책 선호, 대표 여론, 정책 효과 또는 실제 사람의 사용성.

정책 선택 A/B/C는 서버에 서로 다른 입력을 제공하기 위한 균형 데이터일 뿐 연구 결과가 아니다.

## 실제 브라우저 대조

Playwright Chromium으로 공개 참가자 페이지를 별도로 열어 페이지 200 응답과 이벤트 API 폴링을 확인했다. JMeter가 사용한 페이지·API 경로가 실제 UI 흐름과 일치했다.

대조 과정에서 로고 URL 끝에 불필요한 `/`가 붙어 `/aipol-logo.png/`가 404를 반환하는 UI 결함을 발견했다. 참가·폴링·투표 성능에는 영향을 주지 않았지만 후속 수정 대상이다.

## 한계

- JMeter는 브라우저의 JavaScript 렌더링 비용을 그대로 재현하지 않는다.
- 최대 처리량이나 장애가 시작되는 지점까지 올리는 파괴시험은 하지 않았다.
- AI 숙의·응답 분류·외부 모델 호출은 포함하지 않았다.
- 단일 유효 실행 결과이므로 중요한 행사 전에는 재실행을 권장한다.
- PostgreSQL CPU가 순간적으로 높아졌으므로 500명 이상 또는 더 짧은 동시 투표 창은 별도 검증이 필요하다.

## 재현 방법

비공개 운영 앱의 JMeter 계획은 다음 원칙으로 구성됐다.

- Apache JMeter 5.6.3 비GUI 실행
- 참여자별 고유 토큰과 프로파일
- 외부 공개 DNS 사용
- 60초 스레드 상승
- 10초 폴링
- 페이지·폴링·투표별 지연과 오류 분리 집계
- 종료 후 DB 고유 참여자와 투표 완료 수 대조
- 시험 이벤트와 임시 클라우드 자원 제거

원시 JTL, 토큰, 운영 IP와 내부 DB 자료는 개인정보·보안 경계상 공개 저장소에 포함하지 않는다. 공개 보고서에는 재현에 필요한 방법과 비식별 집계만 남긴다.

Publishing checklist

행사 전과 후를 수동 검수합니다.

날짜가 지났다고 사이트 문구를 자동으로 바꾸지 않습니다. 실제 실행 기록을 확인한 뒤 게시합니다.

행사 전

  • 모든 현장 문구가 미래 시제인지
  • 가상 시민 보고서에 실제 여론 아님 고지가 있는지
  • 팀·시간·장소가 최신 행사 안내와 일치하는지
  • 실제 참가자 데이터가 정적 사이트에 없는지

행사 후

  • 실제 실행 단계와 변경 사항을 기록했는지
  • 사전 가상 실험과 실제 데이터를 분리했는지
  • 표본·프레이밍·실패·미반영 한계를 함께 공개했는지
  • 팀 검토 뒤 최종 갱신일을 바꿨는지
i
현재 사이트는 검색엔진에 공개되어 있습니다.

공개 연구 자료와 프로젝트 페이지는 검색엔진이 색인할 수 있습니다. 검토 중인 실험 입력 화면은 계속 검색에서 제외하며, 민감한 자료는 공개 사이트에 포함하지 않습니다.

Publishing checklist

Manual inspection conducted before and after the event.

Site copy is not automatically changed simply because the date has passed. Publication occurs after verifying actual execution records.

Pre-event

  • Whether all on-site copy is in the future tense
  • Whether the virtual citizen report includes a notice that it is not actual public opinion
  • Whether team, time, and location match the latest event information
  • Whether actual participant data is absent from the static site

Post-event

  • Whether actual execution steps and changes were recorded
  • Whether pre-event virtual experiments and actual data were separated
  • Whether limitations regarding sample, framing, failure, and non-reflection were disclosed together
  • Whether the final update date was changed after team review

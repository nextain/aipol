Pull request workflow

From Proposal to Publication

Even automatically generated content undergoes the same review process.

Issue or Proposal

Explain the problem, target, rationale, and scope of disclosure.

Work Branch

Separate code, documents, and case data during creation.

Pull Request

Submit change rationale, verification results, and limitations together.

Human Review

Review facts, methodology, security, and expression.

Merge & Publish

Reflect only approved changes on the site and RSS.

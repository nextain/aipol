Participate · Open source

정책 질문과 연구 방법을 제안하고 함께 만듭니다.

AIPOL은 사례, 방법론, 코드와 지식을 Pull Request로 제안하고 검토하는 오픈소스 연구개발 프로젝트입니다.

CASE

정책 사례 제안

새 정책 질문과 연구·실험 계획을 제안합니다.

METHOD

방법론 검토

AI 역할, 사람 승인, 평가와 방어장치를 비판하고 개선합니다.

CODE

도구 개발

연구 엔진, 온라인 참여, 자동화 봇과 접근성을 개발합니다.

KNOWLEDGE

지식 공유

공식 출처, 해외동향, 번역, 재현 결과와 실패를 추가합니다.

Choose your path

어떤 참여를 찾고 있나요?

연구개발 기여와 행사 설문 참여는 서로 다른 경로입니다.

OPEN SOURCE

연구·개발에 기여

정책 사례, 근거, 방법론, 코드와 번역을 브랜치와 Pull Request로 제안합니다.

현재: 비공개 저장소의 초대된 공동연구자만 참여할 수 있습니다.

EVENT

행사 설문에 참여

사전 등록 참가자는 행사 진행자의 안내에 따라 모바일 설문 화면에서 참여합니다.

현재: 운영 화면 개통 · 설문 회차는 아직 닫힘.

모바일 설문 화면 →
OPERATOR

연구팀·진행자

관리자 화면은 개인정보와 행사 통제를 다루므로 공개 링크로 배포하지 않습니다.

현재: 개인 운영 계정과 편집 가능한 행사 초안이 준비됐으며 링크는 연구팀에 별도 공유합니다.

Pull request workflow

제안부터 공개까지

자동 생성된 콘텐츠도 같은 검토 절차를 거칩니다.

Issue 또는 제안서

문제, 대상, 근거와 공개 범위를 설명합니다.

작업 브랜치

코드·문서·사례 데이터를 분리해 작성합니다.

Pull Request

변경 이유, 검증 결과와 한계를 함께 제출합니다.

사람 검토

사실, 방법론, 보안과 표현을 검토합니다.

병합·발행

승인된 변경만 사이트와 RSS에 반영합니다.

Proposal checklist

정책 사례 PR에 필요한 정보

구현보다 먼저 연구 목적과 책임 구조를 확인합니다.

연구 질문

  • 어떤 정책개발 문제인가
  • 누가 결과를 사용할 것인가
  • AI가 필요한 이유는 무엇인가

검토 구조

  • AI가 맡는 단계
  • 사람이 승인하는 지점
  • 근거·오류·편향 확인 방법

공개 계획

  • 재현 가능한 코드와 기록
  • 개인정보·저작권 경계
  • 실패와 한계의 공개 범위
PR

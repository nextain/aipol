How to use

정책개발의 각 단계에 AI를 연결합니다.

온라인 연구, 전문가 워크숍, 시민 참여, 현장 실험 등 목적에 맞는 방식으로 필요한 단계와 도구를 조합할 수 있습니다.

문제 정의

범위, 목표와 정책 레버를 정합니다.

근거 조사

출처와 불확실성을 구조화합니다.

대안 개발

전문가와 AI가 선택지를 확장합니다.

대안 비교·검토

근거, 이해관계자 조건과 상충하는 관점을 살핍니다.

사람의 판단

수정·선택·승인합니다.

기록·공유

과정, 결과와 한계를 남깁니다.

Ways to apply

연구 목적에 맞게 활용합니다.

모든 사례가 행사나 투표를 필요로 하지는 않습니다.

정책연구

문헌과 근거를 구조화하고 정책 대안과 검토 질문을 개발합니다.

온라인 협업

시간과 장소가 다른 전문가·이해관계자의 의견을 비동기로 수집하고 비교합니다.

워크숍·숙의

전문가 회의나 시민 숙의에서 AI가 쟁점과 추가 대안을 정리하도록 활용합니다.

정책실험

모델, 프롬프트와 절차를 바꾸어 결과 차이와 실패 조건을 검증합니다.

Start a project

사례는 PR로 제안하고 함께 개발합니다.

정책 질문, 사용할 근거, AI의 역할, 사람의 승인 지점과 공개 범위를 먼저 적습니다.

01

사례 제안

정책 문제와 연구 질문, 참여 주체, 예상 산출물을 제안합니다.

02

프로토콜 설계

필요한 단계, 모델, 검토 기준과 방어장치를 프로젝트에 맞춥니다.

03

실행·공유

온라인 또는 현장에서 실행하고 재현 기록과 한계를 사례로 공개합니다.

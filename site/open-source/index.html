정책결정 지원 도구를 검토하고, 반박하고, 확장하세요.

코드뿐 아니라 설계 결정, 사전 실험, 반증된 가설과 알려진 한계를 함께 공개합니다.

참여 방식 보기공개 준비 상태

Repository map

하나의 저장소, 네 종류의 공개 자산

실행 도구와 연구 기록을 분리하되 서로의 근거를 추적할 수 있게 둡니다.

/policy_lab

도메인 중립 코어

레버, 근거, 영향, 프로토콜, 방어장치와 정책 분야 플러그인.

/event-tool

현장 행사 도구

시민 응답, 진행자 작업공간, AI 교차숙의와 보고서.

/instances

실험 기록

실행 데이터, 보고서, provenance와 폐기·교정 계보.

/docs · RFC

설계와 비판

아키텍처, 방법론, 적대 리뷰와 다음 사양.

Repository release

외부 기여를 받기 전에 저장소부터 안전하게 엽니다.

현재 저장소는 비공개이며 코드·이력·문서의 민감정보와 실행 절차를 검토하고 있습니다.

PR
공개 전환 뒤 clone·Issue·Pull Request 링크를 활성화합니다.

지금은 존재하지 않는 공개 경로를 링크하지 않습니다. 공개 준비 상태와 참여 계약은 이 사이트에서 먼저 확인할 수 있습니다.

Contribute

기여는 기능보다 신뢰성을 먼저 봅니다.

방어장치는 프로젝트 헌장입니다. 완화나 우회는 메인테이너 승인과 근거 문서가 필요합니다.

새 정책 분야

근거, 정책 레버, 영향 방향, 세그먼트와 프롬프트를 도메인 플러그인으로 추가합니다.

방어장치·검증

편향, 프레이밍, 재현성, 개인정보, 접근성의 실패 경로와 테스트를 보강합니다.

현장·문서

행사 운영, 보고서 표현, 사용자 연구, 번역과 대외 문서의 정확성을 개선합니다.

기여 계약 살펴보기신뢰 원칙

일반 오류·제안

현재는 참여 페이지의 제안 항목을 확인해 주세요. 저장소 공개 전환 뒤 재현 가능한 설명을 받는 Issue 경로를 엽니다.

보안·참가자 데이터

취약점이나 실제 참가자 데이터 노출 가능성은 향후에도 공개 이슈에 원문을 올리지 않습니다. 저장소 공개 때 비공개 제보 절차를 함께 안내합니다.

Built in the open

Platform

정책개발 연구를 실행하고 공유하는 도구.

연구자에게는 정책개발 엔진과 작업공간을, 참여자에게는 온라인·현장에서 사용할 수 있는 의견 화면을 제공합니다.

구현됨01 / RESEARCH

정책개발 엔진

정책 분야와 공통 절차를 분리하고 레버, 근거, 검토 절차, 프로토콜과 재현 기록을 코드로 표현합니다.

  • 도메인 플러그인
  • 근거와 가정 구조화
  • 프로토콜 검증
  • 모델·프롬프트 기록
MVP02 / WORKSPACE

연구·운영 작업공간

정책 프로젝트를 만들고 대안, 의견수렴, AI 분석, 사람 검토와 보고서를 단계별로 관리합니다.

  • 정책대안 입력·버전 관리
  • 온라인·현장 수집 제어
  • AI 작업 진행·재시도
  • 사람 수정·승인 게이트
MVP03 / PARTICIPATION

온라인 참여 화면

브라우저와 모바일에서 정책안에 대한 입장, 조건, 우려와 이유를 남길 수 있습니다. 같은 화면을 온라인과 현장에서 활용합니다.

  • 모바일·고령 접근성
  • 조건부 의견 수집
  • 회차별 판단 연결
  • 마감·오류·완료 안내

Current boundary

웹 기반 MVP와 공개 온라인 서비스는 구분합니다.

공개 포털과 연금 실험 미리보기는 정적 웹으로 제공됩니다. 별도의 FastAPI·SQLite 연구 도구는 Azure의 영속 저장소, 개인 관리자 계정, 역할·2단계 인증을 갖췄습니다. 현재는 합성 참가자 검토만 열고 실제 참가자 수집은 닫아 둔 통제된 연구·행사 환경입니다.

현재 가능

통제된 온라인·현장 연구

  • 정적 공개 포털·연금 실험 미리보기
  • FastAPI + SQLite 기반 통제형 연구 도구
  • Azure Files 기반 영속 DB·개인 계정·역할·2단계 인증
  • 준비→수집→AI 분석→사람 승인→보고서
  • 실제 수집 OFF 상태의 합성 참가자 전 과정 검토
  • 비식별·합성 기반 정적 보고서 생성
운영 고도화

상시 공개 온라인 운영

  • 다중 행사 확장용 관리형 데이터베이스
  • 장시간 AI 작업용 작업 큐
  • 개인정보 최소수집·파기 체계
  • 외부 AI 전송 고지·동의와 운영 모니터링
